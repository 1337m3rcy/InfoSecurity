# Пояснение к коду

Этот скрипт реализует **шифр Цезаря**, который выполняет циклический сдвиг символов текста на указанное количество позиций. Скрипт поддерживает **русский и английский алфавиты** в нижнем регистре, а также пробел.

## Основные элементы кода

### Константы
- `BASE_ALPHABET`: 
  Объединённый алфавит, включающий:
  - Английский алфавит в нижнем регистре (`abcdefghijklmnopqrstuvwxyz`);
  - Русский алфавит (включая букву "ё") (`абвгдеёжзийклмнопрстуфхцчшщъыьэюя`);
  - Пробел (`' '`).
- `SHIFT_DEFAULT`: 
  Значение сдвига по умолчанию (равно `-3`).

---

### Функция `shift_symbol(symbol: str, shift: int) -> str`
Функция выполняет сдвиг символа на указанное количество позиций (`shift`).

1. **Находит индекс символа в `BASE_ALPHABET`:**
   - Если символ присутствует в алфавите, его индекс сохраняется.
   - Если символ отсутствует, возвращается ошибка (текущая реализация не проверяет это).

2. **Вычисляет новый индекс с учётом сдвига:**
   - Если сдвиг приводит индекс за пределы длины алфавита:
     - При положительном сдвиге выполняется циклический переход в начало.
     - При отрицательном сдвиге выполняется циклический переход в конец.

3. **Возвращает новый символ из `BASE_ALPHABET`, соответствующий сдвинутому индексу.**

**Пример работы функции:**
- Для символа `'a'` с сдвигом `3`: 
  Индекс `0 → 3`, результат — `'d'`.
- Для символа `'я'` с сдвигом `-3`: 
  Индекс `32 → 29`, результат — `'ь'`.

---

### Основной блок программы
Код, заключённый в `if __name__ == '__main__':`, выполняет взаимодействие с пользователем:

1. **Выводит описание шифра:**
   Указывает, что шифр работает с русским и английским алфавитами, а также пробелами.

2. **Запрашивает пользовательский ввод:**
   - Сдвиг (`n`): Пользователь вводит сдвиг. Если ничего не введено, используется значение по умолчанию (`-3`).
   - Текст (`input_text`): Пользователь вводит сообщение для шифрования.

3. **Шифрует текст:**
   - Проходит по каждому символу `input_text`.
   - Для каждого символа вызывает `shift_symbol` с указанным сдвигом.
   - Формирует строку зашифрованного текста.

4. **Расшифровывает текст:**
   - Для каждого символа зашифрованного текста вызывает `shift_symbol` с обратным сдвигом (`-n`).
   - Формирует строку расшифрованного текста.

5. **Выводит результаты:**
   - Исходный текст, сдвиг, зашифрованный и расшифрованный текст.

---

## Пример работы программы

### Ввод
- **Сдвиг:** `-3`
- **Текст:** `hello мир`

### Ход выполнения
1. **Шифрование:**
   - Символ `'h'`: Индекс `7 → 4`, результат `'e'`.
   - Символ `'e'`: Индекс `4 → 1`, результат `'b'`.
   - Символ `'л'`: Индекс `23 → 20`, результат `'и'`.
   - Пробел остаётся на месте.
   - Итог зашифрованного текста: `'ebiil зио'`.

2. **Расшифровка:**
   - Используется обратный сдвиг (`+3`).
   - Итог расшифрованного текста: `hello мир`.
