# Пояснение к коду шифрования RC5

Этот скрипт реализует **шифр RC5**, блочный симметричный шифр, который использует параметризуемые размеры блоков, количество раундов и секретный ключ. Скрипт позволяет шифровать и дешифровать сообщения с использованием шифрования с IV (инициализационным вектором).

## Основные элементы кода

### Константы
- `rc5_const`: Словарь, содержащий значения для различных размеров слова (`w`) в битах:
  - Для 16 бит: `(0xB7E1, 0x9E37)`
  - Для 32 бит: `(0xB7E15163, 0x9E3779B9)`
  - Для 64 бит: `(0xB7E151628AED2A6B, 0x9E3779B97F4A7C15)`

### Класс `RC5`
Класс, реализующий алгоритм шифрования и дешифрования RC5, включает несколько методов для выполнения различных операций.

1. **Инициализация (Constructor `__init__`)**
   - Параметры: размер блока `w` (в битах), количество раундов `r`, секретный ключ `key`.
   - Подготавливает ключи для расширения и мешает их в процессе инициализации.

2. **Методы работы с блоками данных**
   - `_modular_add(a, b)` и `_modular_sub(a, b)`: Операции сложения и вычитания по модулю `2^w`.
   - `_left_rotate(x, n)` и `_right_rotate(x, n)`: Операции побитового сдвига влево и вправо с циклическим переходом.
   
3. **Методы для расширения ключа**
   - `_key_align(key)`: Выравнивание ключа по размеру слова.
   - `_key_extend()`: Расширение ключа в массив под-ключей с использованием констант.
   - `_mix()`: Процесс перемешивания для создания окончательных под-ключей.

4. **Шифрование и дешифрование блока**
   - `encrypt_block(block)`: Шифрует один блок данных, используя под-ключи.
   - `decrypt_block(block)`: Дешифрует один блок данных, используя под-ключи в обратном порядке.

5. **Шифрование и дешифрование сообщений**
   - `encrypt_message(iv, plaintext)`: Шифрует текст, добавляя длину сообщения и используя IV.
   - `decrypt_message(iv, ciphertext)`: Дешифрует зашифрованное сообщение, восстанавливая его первоначальный вид.

---

### Пример работы программы

1. **Инициализация RC5**
   - Задаём параметры: `w = 32` (размер блока 32 бита), `r = 12` (количество раундов), случайный ключ.
   - Генерация случайного IV с помощью `secrets.randbits(w * 2)`.

2. **Шифрование**
   - Для каждого блока текста применяется шифрование с использованием под-ключей.
   - Применяется IV для увеличения безопасности.

3. **Дешифрование**
   - Дешифровка выполняется с использованием тех же под-ключей, но в обратном порядке.
   - IV используется для восстановления исходного текста.

---

### Пример работы программы

#### Ввод
- **Размер блока (w):** `32`
- **Количество раундов (r):** `12`
- **Ключ:** случайный ключ длиной 16 байт.
- **IV:** случайный инициализационный вектор.
- **Текст:** `hello мир`

#### Ход выполнения
1. **Шифрование:**
   - Исходный текст шифруется с использованием RC5.
   - Сначала текст кодируется в байты, затем разбивается на блоки по 32 бита.
   - Каждый блок шифруется с использованием под-ключей и IV.
   - Итоговый зашифрованный текст представляется в виде строки в шестнадцатеричном формате.

2. **Дешифровка:**
   - Зашифрованный текст дешифруется с использованием тех же параметров.
   - Возвращается исходный текст после расшифровки.
