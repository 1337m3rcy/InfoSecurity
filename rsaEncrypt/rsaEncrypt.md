# Пояснение к коду RSA

Этот скрипт реализует алгоритм **RSA**, который является одним из самых популярных методов **асимметричного шифрования**. В алгоритме используется пара ключей: **публичный** и **приватный**. Публичный ключ используется для шифрования сообщений, а приватный — для их расшифровки.

## Основные элементы кода

### Константы и параметры

-   `bit_length`: Определяет размерность ключа в битах. Для тестирования задано значение 8 бит.

### Функции

#### 1. **`mod_inverse(a: int, m: int) -> int`**

Эта функция находит **обратное число** `a` по модулю `m` с использованием алгоритма Евклида. Обратное число необходимо для вычисления приватного ключа.

#### 2. **`is_prime(n: int) -> bool`**

Проверяет, является ли число `n` простым. Для упрощения вычислений используется обычный метод деления.

#### 3. **`generate_keypair(keysize: int) -> tuple`**

Генерирует пару ключей для RSA (публичный и приватный). Включает несколько шагов:

-   Генерация двух простых чисел `p` и `q` с заданной битовой длиной.
-   Вычисление модуля `n` как произведение `p` и `q`.
-   Нахождение открытого ключа `e` и вычисление приватного ключа `d`.

#### 4. **`encrypt_message(message: str, public_key: tuple) -> list`**

Шифрует сообщение, используя публичный ключ. Каждому символу сообщения соответствует число, возведённое в степень `e` по модулю `n`.

#### 5. **`decrypt_message(ciphertext: list, private_key: tuple) -> str`**

Дешифрует сообщение, используя приватный ключ. Каждое число из зашифрованного сообщения возводится в степень `d` по модулю `n` для восстановления исходного текста.

### Основной блок программы

В главной части программы:

1. Генерируются ключи с заданным размером (8 бит).
2. Пользователю предлагается ввести сообщение для шифрования.
3. Сообщение шифруется и выводится в зашифрованном виде.
4. Зашифрованное сообщение расшифровывается и выводится в исходном виде.

## Пример работы программы

1. **Генерация ключей**: Сначала генерируются публичный и приватный ключи.
2. **Шифрование**: Пользователь вводит сообщение, которое затем шифруется с использованием публичного ключа.
3. **Дешифровка**: Зашифрованное сообщение расшифровывается с использованием приватного ключа.

### Пример ввода

```
Enter a message: Hello
```

### Пример вывода

```
Public key: (e, n)
Private key: (d, n)
Encrypted message: [encrypted_numbers]
Decrypted message: Hello
```

## Важные замечания

-   В реальных приложениях для RSA рекомендуется использовать гораздо большие размеры ключей, чтобы обеспечить надёжность шифрования.
